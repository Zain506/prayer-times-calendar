Prayer Times Calendar

Daily prayer start and jamaat times for Islamic Centre Colindale, as a calendar you subscribe to once. It updates itself every week and switches between GMT and BST automatically.

Subscribe

Apple Calendar / Outlook desktop Google Calendar

For any other app, copy this link and add it as a calendar “from URL” / “from the web”:

iPhone, iPad and Mac

  1. Tap the Apple Calendar button above and confirm Subscribe.
  2. Or on iPhone: Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar, and paste the link.

Google Calendar (and Android)

  1. On a computer, use the Google Calendar button, or go to calendar.google.com → + next to “Other calendars” → From URL and paste the link.
  2. On Android it then appears in the Google Calendar app. If not: app Settings → tap the calendar → turn on Sync.

Google refreshes subscribed calendars on its own schedule, which can take up to a day.

Outlook

  1. Outlook on the web / new Outlook: Calendar → Add calendar → Subscribe from web, paste the link.
  2. Classic Outlook for Windows: use the Apple Calendar / Outlook button above, or Home → Add Calendar → From Internet.

Proton Calendar

  1. + next to “My calendars” → Add calendar from URL, paste the link.

What’s in it

Each prayer is one event from its start time to its jamaat time, e.g. “Fajr · jamaat 05:45”. Sunrise is a short marker, and on Fridays each Jumu’ah jamaat gets its own event. Events are marked free, so they don’t block your availability.

Set alerts in your calendar app’s settings for this calendar if you want reminders. Times come from the mosque’s published timetable; always follow the mosque’s notices if they differ.
